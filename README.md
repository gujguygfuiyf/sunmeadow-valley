# 晨露谷物语 · Sunmeadow Valley

基于 **TypeScript + HTML5 Canvas + Vite** 从零构建的 2D 像素田园模拟 RPG 游戏工程框架（灵感源自《星露谷物语》），零运行时第三方依赖，适合本地快速二次开发与长期迭代。

## 核心特性

- **农场与生存节奏**：春夏秋冬四季轮替、晴/微风/雨/雷雨动态天气（雨天自动浇水）、复古电视天气预报、体力/生命管理、农舍厨房烹饪、铁匠铺四阶农具蓄力范围升级（`1 → 3 → 5 → 3×3` 格）与自动洒水器。
- **采集、工匠制作与垂钓**：伐木斧/十字镐/镰刀清理野树岩石杂草，12 种制作配方（24 格储物箱、稻草人、石砌熔炉、果酱桶、酿酒桶、种子机、蛋黄酱机、奶酪机等），以及经典垂直绿条惯性钓鱼小游戏。
- **牧场养殖与地下矿洞**：建造温馨鸡舍与田园大畜棚，领养并抚摸小鸡/奶牛/绵羊收获蛋奶羊毛；探索程序化地下矿洞（`1F–20F+`），开采矿脉宝石、迎战绿/蓝/紫史莱姆并解锁矿洞电梯。
- **小镇社交与社区献祭**：农舍室内自由摆放家具（`F` 键），漫游晨露小镇与 4 位按早/午/晚日程行动的村民聊天送礼、触发 2 心 / 4 心剧情、参与每季第 14 日庆典、接取每日委托、献祭社区中心收集包（永久解锁四季温室与矿车快传）并点亮 34 项图鉴。
- **工程化与拓展钩子**：36 格完整背包、四场景实时像素小地图、Web Audio 四季田园 BGM 与 19 种音效、Schema v3 自动存档，并内置 Tiled JSON（`.tmj`）地图加载器与外部 PNG 精灵表热替换接口。

## 本地运行指南

### 1. 环境要求

- **Node.js** `>= 18`（推荐 `20+` 或 `22+`）
- **npm** `>= 9`

### 2. 安装与启动

```bash
git clone https://github.com/gujguygfuiyf/sunmeadow-valley.git
cd sunmeadow-valley

# 安装开发依赖
npm install

# 启动本地开发服务器
npm run dev
```

启动后在浏览器打开终端提示的地址（默认 `http://localhost:5173`）即可开始游玩！

### 3. 测试与生产构建

```bash
# 运行全部单元测试与数据完整性校验 (Vitest)
npm test

# TypeScript 严格类型检查与生产构建（输出至 dist/）
npm run build

# 本地预览生产构建产物
npm run preview
```

## 常用操作快捷键

| 按键 | 功能 |
| :--- | :--- |
| `W A S D` / `方向键` | 角色移动（探索农场、农舍小屋、晨露小镇、地下矿洞） |
| `1 - 9` / `鼠标滚轮` | 切换底部快捷栏物品 |
| `鼠标左键` / `空格` | 使用工具、播种、浇水、甩竿钓鱼、挥剑攻击、摆放机器 |
| `E` / `鼠标右键` | 收获作物、抚摸动物、与建筑/机器/村民交互、食用手中食物 |
| `I` / `Tab` | 打开 36 格完整大背包 |
| `K` | 打开制作合成工坊 |
| `J` | 查看小镇公告栏每日委托 |
| `C` | 打开社区中心收集包与全图鉴 |
| `V` | 查看村民好感手册 |
| `M` | 打开世界地图与矿车快传 |
| `F` | 在农舍小屋内开启 / 退出自由装修模式 |
| `B` | 快捷打开种子铺 |
| `N` | 直接休息推进至次日清晨 |
